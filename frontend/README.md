# Fifty Frontend — React + TypeScript + Vite

Fifty (SmartCheck) platformasining Telegram WebApp frontend ilovasi.

## 🚀 Texnologiyalar
* **React 18** & **TypeScript**
* **Vite**
* **Lucide React**
* **Cloudflare Pages**

## 📦 Ishga tushirish
```bash
npm install
npm run dev
```

## 🏗 Ishlab chiqarish uchun yig'ish (Build)
```bash
npm run build
```

## 🌐 Cloudflare Pages Deploy
```bash
npx wrangler pages deploy dist --project-name fifty-app --branch main
```
